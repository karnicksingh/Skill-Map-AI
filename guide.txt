E. Interview API Service Fix
----------------------------
- File: frontend/src/features/interview/services/interview.api.js
- Details:
  * BUG: The function destructured `{ resumeFile, selfDescription, jobDescription }`
    while the hook passed `{ resume, selfDescription, jobDescription }`.
    This caused `resumeFile` to be `undefined`, so `formData.append("resume", undefined)`
    was sent to the backend without any actual file.
  * FIX: Renamed `resumeFile` to `resume` to match hook arguments.

F. useInterview Hook Fix
------------------------
- File: frontend/src/features/interview/hooks/useInterview.js
- Details:
  * BUG: `handleGenerateInterviewReport` didn't return `data`. Callers like
    `Home.jsx` received `undefined` when trying to read `data._id`.
  * FIX: Added `return data;` inside `handleGenerateInterviewReport`.

3. BACKEND FIXES
================================================================================

A. PDF Parser Integration
-------------------------
- File: backend/controllers/interview.controller.js
- Details:
  * BUG: The project uses `pdf-parse` v2 (`^2.4.5`), which exports a named class
    `PDFParse` rather than a default function.
  * FIX:
    - Imported correctly: `const { PDFParse } = require("pdf-parse");`
    - Instantiated correctly:
      `const parser = new PDFParse({ data: req.file.buffer });`
      `const result = await parser.getText();`
      `const resumeContent = result.text;`

B. Missing User ID on Report Creation (MongoDB Atlas Fix)
---------------------------------------------------------
- File: backend/controllers/interview.controller.js
- Details:
  * BUG: When generating a report, `interviewReportModel.create()` was called
    without attaching the user's ID (`req.user.id`).
    As a result, reports were saved into MongoDB Atlas with `user: undefined` / `null`.
    When the user visited Previous Reports (`getAllInterviewReportsController`),
    the query `{ user: req.user.id }` returned 0 reports because no reports had
    a matching user ID.
  * FIX: Added `user: req.user.id` to `interviewReportModel.create({...})`.
    Now all generated reports are linked to the authenticated user's MongoDB `_id`.

C. Migration Script for Legacy/Orphaned Reports
-----------------------------------------------
- File: backend/fix-orphaned-reports.js (NEW)
- Details:
  * Utility script to backfill `user: <userId>` onto any historical reports
    that had `user: null` in MongoDB Atlas.

4. VERIFICATION WORKFLOW
================================================================================
1. Login/Register to SkillMap AI.
2. Go to Home (`/`).
3. Upload Resume PDF, provide Job Description & Self Description.
4. Click Submit -> Button changes to "✦ Generating...".
5. Backend parses PDF, prompts Gemini AI, saves report to MongoDB Atlas with
   your user ID, and returns the report.
6. Frontend navigates to `/interview/:interviewId` and displays full dashboard.
7. Click "Previous Reports" -> View all previously saved reports linked to
   your account.
